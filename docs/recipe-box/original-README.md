# Recipe Box

A mobile-first, installable web app that feels like a physical recipe box: the selected card stands in the lid, divider tabs sit in front, and the full recipe card is one tap away. Voice edits with read-back confirmation, audio notes, URL and photo import, Tidy and Wild West looks, and sharing between people.

Status: planning. The specification is in `docs/`; the build is done by AI agents working in parallel lanes.
